# Orgesa Zyberaj Portfolio

A static portfolio website built with HTML, CSS, and JavaScript.

## Publishing

The `Deploy portfolio to GitHub Pages` workflow publishes the site to:

https://orgesazyberaj-prog.github.io/orgesa-zyberaj-portfolio/

The first deployment runs after the workflow is merged to `main`. After that, each push to `main` deploys the site automatically. The workflow can also be run manually from the Actions tab.

To use a shorter custom domain, configure a domain you own in the repository's GitHub Pages settings and point its DNS records to GitHub Pages.
