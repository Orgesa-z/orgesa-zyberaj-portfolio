# Orgesa Zyberaj Portfolio

A static portfolio website built with HTML, CSS, and JavaScript.

## Publishing

The `Deploy portfolio to GitHub Pages` workflow is set up to publish the site to:

https://orgesazyberaj-prog.github.io/orgesa-zyberaj-portfolio/

Before it can publish, a repository owner or administrator must open **Settings > Pages** and set the build and deployment source to **GitHub Actions**. Once enabled and the workflow is merged to `main`, each push to `main` deploys the site automatically. The workflow can also be run manually from the Actions tab.

To use a shorter custom domain, configure a domain you own in the repository's GitHub Pages settings and point its DNS records to GitHub Pages.
